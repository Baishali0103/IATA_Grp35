# Simple Image Description with CNN

This project generates simple images containing two coloured shapes and trains neural network models to predict a sentence describing each image.

Each image contains two objects. Every object has a size, colour and shape. The two objects also have a spatial relationship, such as `above`, `below`, `left of` or `right of`.

Example sentence:

```text
a big blue circle is above a small red square
```

## What the Code Does

This project has three main steps:

1. Generate a synthetic image dataset.
2. Train a neural network to understand the images.
3. Predict natural language descriptions from new images.

The sentence is split into seven parts:

- object 1 size
- object 1 colour
- object 1 shape
- relation
- object 2 size
- object 2 colour
- object 2 shape

Instead of generating a full sentence directly, the model predicts these seven labels separately. The labels are then converted back into a full sentence.

## Dataset Generation

The dataset is generated by `main.py`.

The script creates simple synthetic images. Each image contains two objects, and each object has a size, colour and shape. The two objects also have a spatial relationship.

The generated dataset includes the following attributes:

| Attribute | Values |
|---|---|
| Sizes | small, big |
| Colours | red, blue, green, yellow |
| Shapes | circle, square, triangle |
| Relations | above, below, left of, right of |
| Image size | 128 x 128 |
| Number of samples | 8000 |

The generated images are saved in:

`output/images/`

The metadata file is saved as:

`output/metadata.csv`

The metadata file stores the labels and the full sentence description for each image.

Each row contains:

- sample ID
- object 1 size
- object 1 colour
- object 1 shape
- relation
- object 2 size
- object 2 colour
- object 2 shape
- sentence

## Models

The model definitions are stored in `model.py`.

This project contains three model options.

### CNNMultiHeadSmall

`CNNMultiHeadSmall` is a small convolutional neural network.

It contains several convolution layers followed by a shared fully connected layer. This model is used as a simple baseline.

### CNNMultiHeadDeep

`CNNMultiHeadDeep` is a deeper convolutional neural network.

It uses more convolution layers and batch normalization. This model is designed to learn stronger image features than the smaller CNN.

### ResNet18MultiHead

`ResNet18MultiHead` uses a pretrained ResNet18 model.

The original final layer of ResNet18 is replaced with a custom multi-head output layer for this task. This allows the model to use pretrained image features while still predicting the custom labels used in this project.

The model can be selected in `train.py` by changing:

`MODEL_NAME = "small"`

Available options are:

- `small`
- `deep`
- `resnet18`

## Multi-Head Output Design

All models use a multi-head output design.

Instead of predicting the whole sentence as one class, the model predicts each part of the sentence separately.

The seven predicted parts are:

- object 1 size
- object 1 colour
- object 1 shape
- relation
- object 2 size
- object 2 colour
- object 2 shape

Each part has its own output head.

For example, the model may predict:

- object 1 size: big
- object 1 colour: blue
- object 1 shape: circle
- relation: above
- object 2 size: small
- object 2 colour: red
- object 2 shape: square

These labels are then converted into a sentence:

`a big blue circle is above a small red square`

This design makes the prediction easier to evaluate because the model can be checked both on the full sentence and on each individual sentence component.

## How to Run

### 1. Generate the dataset

Run:

`python main.py`

This creates the generated images and metadata file.

Output files:

- `output/images/`
- `output/metadata.csv`

### 2. Choose a model

Open `train.py` and set the model name.

Example:

`MODEL_NAME = "small"`

Available model names:

- `small`
- `deep`
- `resnet18`

### 3. Train the model

Run:

`python train.py`

The dataset is split into three parts:

| Split | Ratio |
|---|---|
| Training | 70% |
| Validation | 20% |
| Test | 10% |

During training, the script prints the training loss, validation loss, exact match accuracy and slot-level accuracy.

The best model is saved in the `checkpoints/` folder.

Checkpoint examples:

- `checkpoints/small_best.pt`
- `checkpoints/deep_best.pt`
- `checkpoints/resnet18_best.pt`

### 4. Predict example sentences

Open `predict.py` and set the same model name as the checkpoint you want to use.

Example:

`MODEL_NAME = "small"`

Then run:

`python predict.py`

The script prints the original sentence and the predicted sentence for several random samples.

## File Descriptions

### `main.py`

Generates the synthetic dataset.

It randomly creates two objects, assigns their size, colour and shape, chooses a spatial relation, draws the image and saves the matching sentence description.

### `dataset.py`

Defines the PyTorch dataset class.

It loads images from `output/images/` and reads labels from `output/metadata.csv`.

It returns the image tensor, the label dictionary and the original sentence.

### `model.py`

Contains the model definitions.

It includes:

- `CNNMultiHeadSmall`
- `CNNMultiHeadDeep`
- `ResNet18MultiHead`
- `MultiHeadOutput`

The `MultiHeadOutput` class creates the seven output heads used to predict the sentence components.

### `train.py`

Trains and evaluates the selected model.

It loads the dataset, splits it into training, validation and test sets, trains the model, saves the best checkpoint and prints the final test results.

### `predict.py`

Loads a trained model checkpoint and predicts sentences for random samples.

It prints both the gold sentence and the predicted sentence.

### `utils.py`

Stores helper dictionaries and functions.

It contains the mappings between text labels and numerical IDs, such as size, colour, shape and relation mappings.

It also contains the function that converts predicted labels back into a sentence.

## Evaluation

The project uses two main evaluation methods.

### Exact Match Accuracy

Exact match accuracy checks whether the entire predicted sentence is correct.

A prediction is counted as correct only when all seven sentence components are predicted correctly.

For example, this prediction is correct:

Gold sentence:

`a big blue circle is above a small red square`

Predicted sentence:

`a big blue circle is above a small red square`

If even one component is wrong, the sentence is counted as incorrect.

### Slot Accuracy

Slot accuracy checks each sentence component separately.

The evaluated slots are:

- object 1 size
- object 1 colour
- object 1 shape
- relation
- object 2 size
- object 2 colour
- object 2 shape

This is useful because it shows which parts of the sentence the model predicts well and which parts are more difficult.

## Notes

Run `main.py` before running `train.py`, because the training script needs the generated images and metadata file.

Make sure `output/metadata.csv` exists before training.

Make sure the selected checkpoint exists before running `predict.py`.

The model name in `predict.py` must match the checkpoint you want to load.

For example, if you want to use:

`checkpoints/small_best.pt`

then set:

`MODEL_NAME = "small"`

Different models are saved with different checkpoint names, so training one model will not overwrite the weights of another model.

The checkpoint files are saved in the `checkpoints/` folder.
