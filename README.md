# COMPARISON TO COMMERCIAL LLM GPT-4o

To evaluate the performance of our trained CNN models against a commercial LLM, we used the GPT-4o model via the OpenAI API.
GPT-4o was prompted to generate a single sentence describing each test image across all three datasets (Shapes, Numbers, TicTacToe). The same evaluation metrics used for the CNN models — BLEU-4, METEOR, and BERTScore — were applied to the GPT-4o predictions.
